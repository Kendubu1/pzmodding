module Base
{
    /*
        The Fate Token. Carrying one when you die spends it: Permadeath Lock
        records the death but does not lock you out, and your next character
        collects the skills the dead one had.

        Build 42 item syntax - ItemType replaces Build 41's Type.

        DisplayCategory is a stock Build 42 one, deliberately. A category the
        game does not already have a name for renders as its own translation
        key in the inventory, and two goes at supplying that name ourselves both
        came back showing "IGUI_ItemCat_..." to the player: first "Misc", which
        Build 42 no longer has, then our own "Fate".

        "Junk" is where Build 42 files oddments, and it needs nothing from us -
        Junk Jet uses it, ships no label for it, and reads correctly in game.
        A right category name beats a right-looking one we have to supply.
    */
    item FateToken
    {
        DisplayCategory = Junk,
        ItemType = base:normal,
        DisplayName = Fate Token,
        Icon = FateToken,
        Weight = 0.1,
        Tooltip = Tooltip_FateToken,
    }
}
