module JunkJet
{
    imports

        Base,JunkJet

    /*
        Build 42 crafting. The Build 41 `recipe` block is gone; B42 uses
        `craftRecipe` with inputs/outputs. Format verified against a shipping
        B42 mod (VanillaAppliancesExtended), not guessed.

        Checked against a shipping B42 mod with 300 recipes, which settled
        three things that had been guessed:
          - NeedToBeLearn keeps Build 41's capitalisation. It was lowercase
            here, which is a script key that would not have matched.
          - A drainable is `item 1 ... mode:keep flags[MayDegrade]`, and the
            game does the draining. This asked for 90 blowtorches and destroyed
            them.
          - `category` is free-form; a mod names whatever category it likes, so
            "Weapons" parses. Whether it groups with vanilla's weapon recipes in
            the crafting UI is cosmetic and still unconfirmed.

        STILL UNVERIFIED: Base.Pipe. Build 42 is understood to have renamed
        MetalPipe, but neither reference mod uses one, so this is the one item
        here taken on documentation alone. `/additem Base.Pipe` in game settles
        it in a second.

        The long junk list below is temporary. The planned ammo rework makes
        every carryable item valid ammo and deletes this entirely.
    */

    craftRecipe MakeJunkJetAmmo
